J'essaie d'afficher des choses sur un écran Waveshare 3,5" Capacitive Touch LCD (320x480) connecté à un Raspberry PI Zero W v1.1 via GPIO SPI.
Ce qui fonctionne :
- Le rétroéclairage fonctionne via GPIO18 (sudo pinctrl set 18 op dh allume l'écran)
- dtparam=spi=on est activé
- Le module spi_bcm2835 est chargé
- Les GPIO 9/10/11 sont en mode SPI (a0)
- spi0.0 et spi0.1 exisent dans /sys/bus/spi/devices/.
- /dev/fb1 existe
- présence du fichier de commandes d’initialisation du ST7796S (/lib/firmware/st7796s.bin)
- fbset -fb /dev/fb1 retourne une résolution 480x320 RGB565
- Ecrire dans /dev/fb1 modifie son contenu (tests MD5 concluant), sans modifier l'affichage
- /dev/spidev0.1 existe
- GPIO18 est en sortie (op), GPIO25 est en sortie (op), GIO27 est en sortie (op)
- Le framebuffer est bien associé au périphérique SPI0.0. fb1 -> .../spi0/spi0.0/graphics/fb1
- pilote ST7796S (/sys/bus/spi/drivers/panel-mipi-dbi-spi => spi:st7796s)
- extrait de configuration /boot/firmware/config.txt : 
dtparam=spi=on
[all]
dtoverlay=mipi-dbi-spi,speed=16000000
dtparam=compatible=st7796s\0panel-mipi-dbi-spi
dtparam=width=320,height=480,width-mm=49,height-mm=79
dtparam=reset-gpio=27,dc-gpio=25,backlight-gpio=18
- Connectivité actuelle : VCC = pin 2 (5V) ; 3V3 = pin 1 (3V3) ; GND = pin 6 (Ground) ; MISO = pin 21 (GPIO 9)
MOSI = pin 19 (GPIO 10) ; SCLK = pin 23 (GPIO 11) ; SD_CS = pin 26 (GPIO 7) ; LCD_CS = pin 24 (GPIO 8) ; LCD_DC = pin 22 (GPIO 25)
LCD_RST = pin 13 (GPIO 27) ; LCD_BL = pin 12 (GPIO 18) ; TP_SDA = pin 3 (GPI0 2) ; TP_SCL = pin 5 (GPIO 3)
INT = pin 7 (GPIO 4) ; RST = pin 11 (GPIO 17)
- Fonctionnalité : paul@pi:~ $ od -An -tc -N16 /lib/firmware/st7796s.bin
   M   I   P   I       D   B   I  \0  \0  \0  \0  \0  \0  \0 001
- Ecran éteint : cat /sys/class/graphics/fb1/blank => 4

Ce qui ne fonctionne pas:
- Aucun affichage à l'écran malgré l'écriture dans /dev/fb1 bien qu'il ait fonctionné à un moment.
- L'écran reste noir (hors rétroéclairage)

Question : j'aimerai simplement afficher de manière pérenne quelque chose à l'écran pour vérifier que tout fonctionne correctement. 
Que dois-je faire ?

from PIL import Image

chemin = "/home/paul/image.png"

im = Image.open(chemin).convert("RGB")
im = im.resize((320, 480))
im = im.transpose(Image.Transpose.ROTATE_90).transpose(Image.Transpose.ROTATE_270)

with open("/dev/fb1", "wb") as f:
    for y in range(480):
        ligne = bytearray()
        for x in range(320):
            r, g, b = im.getpixel((x, y))
            pixel = ((r >> 3) << 11) | ((g >> 2) << 5) | (b >> 3)
            ligne.extend((pixel & 255, pixel >> 8))
        f.write(ligne)
